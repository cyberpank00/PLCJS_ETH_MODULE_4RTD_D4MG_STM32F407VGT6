# Инструменты 4RTD — калибровка и конфигурирование по Modbus TCP

Два эквивалентных клиента (выберите удобный) для настройки и автоматизированной
калибровки модуля 4RTD:

- `calibrate.mjs` — Node.js 18+, без внешних npm-пакетов (`node:net`, `node:readline`)
- `calibrate.py` — Python 3.8+, только стандартная библиотека (`socket`, `struct`)

Оба реализуют встроенный Modbus TCP клиент и одинаковый диалог.

## Зачем нужна калибровка

Модуль измеряет отношение `R_raw = code/32768 × RREF_ном`. В цепи опорного
резистора стоит аналоговый ключ `ADG849`, паразитное сопротивление которого
(Ron) и допуск `±0.1 %` резисторов `RREF` заранее неизвестны. Поэтому каждый
канал калибруется отдельно для каждого диапазона по линейной модели:

```
R_true = gain × R_raw + offset
```

`gain` убирает ошибку `RREF`, `offset` — Ron ключа. Коэффициенты находятся
методом наименьших квадратов по ≥ 2 эталонным точкам, поданным поверенным
магазином сопротивлений **АКИП-2202А (0.05 %)**. Итог — заявленные **0.2 %**
на канал.

## Диапазоны

| Диапазон | RREF ном. | Резисторы на плате | Для шкал |
|---|---|---|---|
| low  | ~400 Ω  | 2×200 (0.1 %)  | 50 / 100 Ω (50М..Pt100) |
| high | ~4000 Ω | 2×2k (0.1 %)   | 500 / 1000 Ω, 0…2 кОм, 0…5 кОм |

Диапазон выбирается автоматически по типу датчика; во время калибровки
инструмент временно форсирует нужный диапазон (регистр `CALRANGE`).

## Порядок калибровки одного канала

1. Подключите АКИП-2202А к клеммам канала по **3-проводной** схеме.
2. Запустите:
   ```
   node calibrate.mjs calibrate --ch 0 --ip 192.168.142.150
   # или
   python calibrate.py calibrate --ch 0 --ip 192.168.142.150
   ```
3. Инструмент форсирует диапазон и попросит подать эталонные сопротивления.
   Для каждой точки: выставьте значение на калибраторе, введите это значение
   в Ω, инструмент усреднит `R_raw`. Наберите ≥ 2 точки (рекомендуется 3–5,
   ближе к краям шкалы), затем `done`.
4. Инструмент вычислит `gain/offset`, покажет максимальную невязку и запишет
   коэффициенты. Повторит для второго диапазона.
5. В конце предложит сохранить во Flash (`SAVE`), после чего вернёт авто-выбор
   диапазона.

Рекомендуемые точки:
- low: ~50, ~200, ~390 Ω
- high: ~500, ~2000, ~3900 Ω

> Примечание: диапазон high с `RREF≈4 кОм` уверенно перекрывает 0…2 кОм; для
> шкалы 0…5 кОм измеряется до ~4 кОм (ограничение опорного резистора платы).

## Другие команды

```
# Текущие показания всех каналов
node calibrate.mjs status
python calibrate.py status

# Настроить канал: тип шкалы, включение, α
node calibrate.mjs set --ch 0 --type Pt100 --enable 1
python calibrate.py set --ch 1 --type 100P            # русская платина, α ГОСТ
python calibrate.py set --ch 2 --type Pt100 --w100 1.3852   # custom α производителя
```

Допустимые имена типов (`--type`):
`50M, Cu50, 50P, Pt50, Ni100, 100M, Cu100, 100P, Pt100, Ni500, 500M, Cu500,
500P, Pt500, Ni1000, 1000M, Cu1000, 1000P, Pt1000, R2k, R5k`.

Параметры по умолчанию: `--ip 192.168.142.150 --port 502 --unit 1`.
