# Инструменты 4RTD — калибровка и конфигурирование по Modbus TCP

Два эквивалентных клиента (выберите удобный) для настройки и автоматизированной
калибровки модуля 4RTD (плата HW2.1, АЦП `ADS1220`):

- `calibrate.mjs` — Node.js 18+, без внешних npm-пакетов (`node:net`, `node:readline`)
- `calibrate.py` — Python 3.8+, только стандартная библиотека (`socket`, `struct`)

Оба реализуют встроенный Modbus TCP клиент и одинаковый диалог.

## Зачем нужна калибровка

Модуль измеряет отношение `R_raw = code/2²³ × 2·RREF_ном / gain_PGA`. Допуск
`±0.1 %` опорного резистора `RREF` и ошибка усиления PGA заранее неизвестны,
поэтому каждый канал калибруется отдельно для каждого **класса усиления** по
линейной модели:

```
R_true = gain × R_raw + offset
```

Коэффициенты находятся методом наименьших квадратов по ≥ 2 эталонным точкам,
поданным поверенным магазином сопротивлений **АКИП-2202А (0.05 %)**.

## Классы усиления

| Класс | PGA | Полная шкала | Для шкал |
|---|---|---|---|
| 0 | 16 | 250 Ω  | 50М, Cu50, 50П, Pt50 |
| 1 | 8  | 500 Ω  | Ni100, 100М, Cu100, 100П, Pt100, `R200` |
| 2 | 2  | 2000 Ω | Ni500, 500М, Cu500, 500П, Pt500 |
| 3 | 1  | 4000 Ω | Ni1000, 1000М, Cu1000, 1000П, Pt1000 |
| 4 | 1  | 4000 Ω | `R2k` |

Класс выбирается автоматически по типу датчика; во время калибровки инструмент
временно форсирует нужный класс (регистр `20 + ch`, значение `класс + 1`).

## Одноразовая запись (write-once) — читать перед калибровкой

Коэффициенты в регистрах `540+` — **живой предпросмотр** (действуют до
перезагрузки). Постоянное хранение — команда **COMMIT** (`HR131 = 0xCA00 |
(ch×5 + класс)`), которая программирует слот в отдельном секторе Flash и
**блокирует его навсегда** (20 слотов: 4 канала × 5 классов). Инструмент
после расчёта спрашивает подтверждение — нужно набрать слово `COMMIT`.
Любой другой ответ оставляет предпросмотр без фиксации.

Разблокировать слот можно только аварийным стиранием всего сектора
(`HR132 = 0xC1A5` + удержание кнопки `FACT_RES`), см. README репозитория.

## Порядок калибровки одного канала

1. Подключите АКИП-2202А к клеммам канала по **3-проводной** схеме.
2. Настройте тип датчика (класс возьмётся из него) или укажите класс явно:
   ```
   node calibrate.mjs calibrate --ch 0 --ip 192.168.1.12          # класс по типу
   node calibrate.mjs calibrate --ch 0 --class 1 --ip 192.168.1.12
   # или
   python calibrate.py calibrate --ch 0 --cls 1 --ip 192.168.1.12
   ```
3. Инструмент форсирует класс и попросит подать эталонные сопротивления.
   Для каждой точки: выставьте значение на калибраторе, введите это значение
   в Ω, инструмент усреднит `R_raw` (8 отсчётов). Наберите ≥ 2 точки
   (рекомендуется 3, ближе к краям шкалы), затем `done`.
4. Инструмент вычислит `gain/offset`, покажет максимальную невязку и запишет
   коэффициенты как предпросмотр.
5. Проверьте невязку; если устраивает — наберите `COMMIT`. Затем инструмент
   вернёт авто-выбор класса.

Рекомендуемые точки:
- класс 0: ~20, ~100, ~200 Ω
- класс 1: ~50, ~200, ~400 Ω
- класс 2: ~200, ~1000, ~1900 Ω
- классы 3/4: ~500, ~2000, ~3800 Ω

## Другие команды

```
# Текущие показания всех каналов (+ тип, класс, int16-представление, блокировки)
node calibrate.mjs status
python calibrate.py status

# Настроить канал: тип шкалы, включение, α
node calibrate.mjs set --ch 0 --type Pt100 --enable 1
python calibrate.py set --ch 1 --type 100P            # русская платина, α ГОСТ
python calibrate.py set --ch 2 --type Pt100 --w100 1.3852   # custom α производителя
```

Допустимые имена типов (`--type`):
`50M, Cu50, 50P, Pt50, Ni100, 100M, Cu100, 100P, Pt100, Ni500, 500M, Cu500,
500P, Pt500, Ni1000, 1000M, Cu1000, 1000P, Pt1000, R200, R2k`.

Параметры по умолчанию: `--ip 192.168.1.12 --port 502 --unit 1`.
