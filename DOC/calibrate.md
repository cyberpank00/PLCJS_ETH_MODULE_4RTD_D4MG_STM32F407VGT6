# Калибровка 4RTD HW2.1: протокол от 2026-10-02

Запись о заводской калибровке конкретного экземпляра платы: какие эталоны использовались, какие сырые значения сняты и какие коэффициенты зафиксированы. Общая процедура и регистры описаны в `README.md`.

- Модуль: 4RTD HW2.1 (ADS1220 x 4), прошивка 2.10, адрес `192.168.1.12`.
- Модель: `R_cal = gain * R_raw + offset`, слот на пару (канал, класс усиления), `slot = ch*5 + class`.
- Регистры слота: `540 + ch*20 + class*4` (gain: +0/+1, offset: +2/+3, float32).
- Итог: **все 20 слотов зафиксированы**, маска блокировок IR127/128 = `0xFFFFF`.
- Подключение эталонов: трёхпроводное, резистор между S+ и E, перемычка S- и E у самого резистора.

## Эталоны

Номиналы измерены цифровым калибратором в режиме омметра (предел 500 Ω для A, B; предел 5 kΩ для C, D). Измерены отдельно от модуля.

| Обозн. | Номинал | Измерено, Ω | Неопределённость по спецификации калибратора |
|---|---|---|---|
| A | ~120 Ω | 119.51 | +-0.16 Ω (0.05 % + 10 емр) |
| B | ~240 Ω | 239.38 | +-0.22 Ω |
| C | ~1000 Ω | 997.7 | +-1.0 Ω (0.05 % + 5 емр) |
| D | ~2000 Ω | 2003.4 | +-1.5 Ω |

Номинал C записан пользователем как 0.9977 kΩ. Резистор 9978 Ω из первого сообщения был опечаткой.

Эталоны выше шкалы класса в зачёт не шли (канал уходит в насыщение): шкалы классов 0/1/2/3/4 равны 250 / 500 / 2000 / 4000 / 4000 Ω.

## Первая калибровка (4 слота)

Классы форсировались регистрами `HR20..HR23` (значение = класс + 1). Резисторы переставлялись по кругу (4 раскладки). Значения R_raw, Ω (среднее по 12 отсчётам, шум σ ≤ 0.013 Ω).

| 3 | CH0, c3 | 119.51 -> 119.917; 239.38 -> 240.182; 997.7 -> 1000.915; 2003.4 -> 2009.885 | 0.996788 | -0.0205 |
| 5 | CH1, c0 | 239.38 -> 239.443; 119.51 -> 119.522 | 0.999575 | +0.0388 |
| 11 | CH2, c1 | 119.51 -> 119.526; 239.38 -> 239.426 | 0.999750 | +0.0139 |
| 16 | CH3, c1 | 119.51 -> 119.605; 239.38 -> 239.589 | 0.999050 | +0.0186 |

CH0 c3: остатки после калибровки не более 0.02 Ω. Проверка CH3 после предпросмотра: `R_cal` = 119.510 при эталоне 119.51.

## Все зафиксированные коэффициенты

`gain / offset (Ω)`; слоты, помеченные (1), записаны первой калибровкой, остальные второй.

| Канал | c0 (x16) | c1 (x8) | c2 (x2) | c3 (x1) | c4 (= c3) |
|---|---|---|---|---|---|
| CH0 | 0.996450 / +0.0177 | 0.996649 / -0.0012 | 0.996773 / -0.0243 | 0.996788 / -0.0205 (1) | 0.996788 / -0.0205 |
| CH1 | 0.999575 / +0.0388 (1) | 0.999683 / +0.0129 | 0.999766 / +0.0037 | 0.999806 / -0.0095 | 0.999806 / -0.0095 |
| CH2 | 0.999500 / +0.0148 | 0.999750 / +0.0139 (1) | 0.999837 / -0.0326 | 0.999866 / -0.0363 | 0.999866 / -0.0363 |
| CH3 | 0.998950 / +0.0216 | 0.999050 / +0.0186 (1) | 0.999179 / +0.0163 | 0.999212 / +0.0112 | 0.999212 / +0.0112 |

Коэффициенты округлены до 6 знаков для gain и 4 знаков для offset; в Flash записан float32 от значений МНК. При записи 16 слотов readback регистров совпал с расчётом. После коммита чтение всех 20 слотов с модуля повторно не выполнялось (канал был перехвачен VPN).

Для слотов (1) вторая серия измерений дала немного другие значения (CH1 c0: 0.999566 / +0.0348, CH2 c1: 0.999817 / -0.0041, CH3 c1: 0.999083 / +0.0127). Они не применялись, потому что слоты уже были залочены; расхождение в пределах шума.

## Остатки подгонки (максимум, Ω)

Две точки: подгонка точная, остаток 0 по построению. Три и четыре точки: CH0 c2 0.003, CH0 c3 0.015, CH1 c2 0.002, CH1 c3 0.003, CH2 c2 0.002, CH2 c3 0.008, CH3 c2 0.0002, CH3 c3 0.020.

Доказательная сила ограничена: эталоны покрывают 120..2003 Ω, то есть около половины шкалы класса 3 и не более ~48 % шкалы класса 1. Выше точек экстраполяция опирается на линейность тракта.

## Где лежат исходные данные

Файлы лежат вне репозитория и могут быть удалены:

- `%TEMP%\rtd_cal_data.json`: сырые точки второй калибровки (`ch_class` -> список `{ref, raw}`).
- `%TEMP%\rtd_cal_fit.json`: коэффициенты МНК (до округления) по всем слотам.
- Скрипты: `rtd_sweep_iter.mjs` (снятие раскладки по классам 0..3), `rtd_fit.mjs` (МНК), `rtd_preview_all.mjs` (предпросмотр и readback), `rtd_commit16.mjs` (фиксация слотов).

## Если понадобится повторить

Слоты write-once. Повторная калибровка возможна только после аварийного стирания сектора 11 (`HR132 = 0xC1A5` и подтверждение физической кнопкой), которое стирает все 20 слотов. Новые эталоны (больше четырёх, значения выше 2 кОм и 300..450 Ω) стоит взять сразу в расчёт.
